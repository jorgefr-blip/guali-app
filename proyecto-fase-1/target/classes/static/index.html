Cómo usar guali

  1. Abre una lección desde el menú Lecciones.
  2. Lee las instrucciones en el panel izquierdo.
  3. Escribe el código manualmente en el editor; evita copiar y pegar, es parte del aprendizaje.
  4. Presiona Compilar y revisa el resultado en la consola.
  5. Si la compilación fue exitosa, presiona Ejecutar.

Puedes ajustar el tamaño de fuente y el tema (claro/oscuro) desde el menú Configuración en cualquier momento.
