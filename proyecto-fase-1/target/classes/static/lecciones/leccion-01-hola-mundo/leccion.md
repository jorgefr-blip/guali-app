# Hola Mundo

Toda persona que aprende a programar en Java escribe primero un programa
que imprime un saludo en pantalla. Esta lección te pide reproducir ese
primer paso **escribiendo el código manualmente**, sin copiar y pegar.

## Instrucciones

1. Escribe una clase pública llamada `HolaMundo`.
2. Dentro de ella declara el método `main`.
3. Usa `System.out.println` para imprimir el mensaje `Hola, mundo`.

## Código de referencia

```
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola, mundo");
    }
}
```

Cuando termines de escribirlo en el editor, presiona **Compilar** y luego
**Ejecutar** para ver el resultado en el Panel de Consola.

> Nota: en esta fase del proyecto los botones Compilar y Ejecutar todavía
> no están conectados al compilador real; esa integración con
> `guali-dev.jar` se agrega en la Fase 2.
